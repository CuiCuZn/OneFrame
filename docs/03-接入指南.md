# 接入指南

平台里只有三个概念：

| 概念 | 是什么 | 例子 |
| --- | --- | --- |
| **渠道** | 一个 API 地址 + 一组密钥 | `https://api.openai.com/v1` + 3 个 key |
| **密钥** | 属于渠道，可多个；401/429 冷却，下次任务换用 | `sk-a...`、`sk-b...` |
| **模型** | 一个渠道 + 一个上游模型名 | 「A厂 · a 模型」「C厂 · a 模型」 |

**一个模型只走一个厂商**。A 厂的 a 模型和 C 厂的 a 模型是两个独立选项，各建一条记录；选中哪个就只请求哪个，失败就是失败，不会自动切到另一家。

同一渠道可以有多个 Key 分摊任务；**401/403/429** 会让当前 Key 冷却，下一次任务换用其他 Key，但**当次任务不会重试**。5xx、超时、内容拒绝同样直接失败。

## 一、OpenAI Images 兼容（最常见）

适合：OpenAI 官方、绝大多数中转/聚合站、one-api / new-api 网关。

| 字段 | 填法 |
| --- | --- |
| 协议 | OpenAI Images 兼容 |
| 服务地址 | `https://api.openai.com/v1` 或 `https://你的中转/v1`（**包含 `/v1`**） |
| 密钥 | 每行一个 |
| 上游模型 | 站点文档里的模型名，如 `gpt-image-1`、`dall-e-3`、`flux-dev` |

能力配置建议：

- 参考图上限：GPT Image / Flux Kontext 类填 4–16；纯文生图填 0。
- 单次张数：官方 `n` 上限 10，多数中转 1–4。
- 支持能力：勾选「参考图」；若站点支持 `seed`，勾选随机种子。
- 尺寸不需要在这里配置：创作台统一选画幅（1:1 / 4:3 / 3:4 / 16:9 / 9:16）与清晰度（1K / 2K / 4K），适配器会换算成具体像素。

请求行为：无参考图走 `POST /images/generations`（JSON）；有参考图走 `POST /images/edits`（multipart，`image[]`）。返回格式在模型编辑里选，默认 `response_format=url`（多数中转站只支持 URL）；只有确认站点支持时才改成 `b64_json`。返回同时兼容 `data[].b64_json`、`data[].url`、`images[]`、`output[]`。

## 二、OpenAI Videos 兼容

适合：OpenAI Sora、以及实现了 `/v1/videos` 任务协议的网关。

| 字段 | 填法 |
| --- | --- |
| 协议 | OpenAI Videos 兼容 |
| 服务地址 | `https://api.openai.com/v1` |
| 上游模型 | `sora-2` 等 |

流程：`POST /videos` → 返回 `id` → 轮询 `GET /videos/{id}` → 完成后 `GET /videos/{id}/content` 下载 MP4。带参考图时用 multipart `input_reference`（首帧）。

参数：`resolution`（480p / 720p / 1080p）、`seconds`（如 `4`）。一次只能生成一个视频。

## 三、Google Gemini / Imagen / Veo

| 字段 | 填法 |
| --- | --- |
| 协议 | Google Gemini / Imagen 或 Google Veo 视频 |
| 服务地址 | `https://generativelanguage.googleapis.com/v1beta` |
| 密钥 | Google AI Studio 的 `AIza...` |
| 上游模型 | 图像 `gemini-2.5-flash-image` / `imagen-4.0-generate-001`；视频 `veo-3.0-generate-001` |

- `gemini-*-image` 走 `:generateContent`，支持多张参考图（`inline_data`），参数 `aspect_ratio`（`1:1 / 3:4 / 4:3 / 16:9 / 9:16`）。
- `imagen-*` 走 `:predict`，暂不支持参考图，`sampleCount` 控制张数。
- Veo 走 `:predictLongRunning`，轮询 operation，完成后带 `key` 下载视频；支持一张首帧图与 `duration`。

> 如果使用自建 Gemini 代理，把服务地址换成代理根地址即可；适配器会拼 `/models/...`。

## 四、自定义 JSON 接口

适合：火山方舟、可灵、MiniMax、以及任何"请求/响应结构不标准"的 HTTP 接口。

在「添加模型 → 自定义接口模板（JSON）」里填写；它等价于模型记录上的 `overrides`。模板字段：

```jsonc
{
  "method": "POST",                 // 可选，默认 POST
  "path": "/v1/images/generations", // 相对服务地址
  "body": {                          // 请求体，支持占位符
    "model": "{{model}}",
    "prompt": "{{prompt}}",
    "n": "{{count}}",
    "size": "{{size}}"
  },
  "auth_header": "bearer",          // 或 "x-api-key"
  "refs": {                          // 可选：参考图怎么带
    "mode": "data_url",              // data_url | data_url_array | b64
    "field": "image"
  },
  "response": {                      // 同步接口：从响应里取图
    "items": "data",
    "url": "url",
    "b64": "b64_json"
  },
  "poll": {                          // 异步接口才需要
    "path": "/v1/tasks/{{id}}",
    "status": "status",
    "success": ["succeeded", "completed"],
    "failure": ["failed", "error"],
    "progress": "progress",
    "items": "output.images",
    "url": "url",
    "b64": "b64_json",
    "interval": 3
  }
}
```

占位符：`{{prompt}}` `{{negative}}` `{{model}}` `{{count}}` `{{size}}` `{{aspect}}` `{{seed}}` `{{duration}}` `{{resolution}}` `{{id}}` `{{base_url}}`。图像请求里的 `{{size}}` 会按创作台选择的画幅 + 1K/2K/4K 自动换算，不需要手动填。占位符独占整个字符串时会保留数字类型（如 `"n": "{{count}}"` → `2`）。

### 例 1：火山方舟 Seedream（同步）

服务地址 `https://ark.cn-beijing.volces.com/api/v3`，协议选「自定义 JSON 接口」，模板：

```json
{
  "path": "/images/generations",
  "body": {
    "model": "{{model}}",
    "prompt": "{{prompt}}",
    "size": "{{size}}",
    "response_format": "url",
    "watermark": false
  },
  "refs": { "mode": "data_url_array", "field": "image" },
  "response": { "items": "data", "url": "url" }
}
```

上游模型填 `doubao-seedream-4-0-250828` 之类的 model id。参考图数量按方舟文档配置（如 14 张）。

### 例 2：异步视频（提交 → 轮询 → 取 URL）

```json
{
  "path": "/v1/videos/text2video",
  "body": {
    "model_name": "{{model}}",
    "prompt": "{{prompt}}",
    "duration": "{{duration}}",
    "aspect_ratio": "{{aspect}}"
  },
  "response": { "id": "data.task_id" },
  "poll": {
    "path": "/v1/videos/text2video/{{id}}",
    "status": "data.task_status",
    "success": ["succeed"],
    "failure": ["failed"],
    "progress": "data.progress",
    "items": "data.task_result.videos",
    "url": "url"
  }
}
```

注意：

- `response.id` 指向任务号；一旦存在 `poll`，就按异步处理。
- 轮询成功后从 `poll.items` 指定的数组里逐项取 `poll.url` / `poll.b64`。
- 需要鉴权的下载地址可以带 token：结果 URL 会直接 GET，如果站点要求签名，请在返回的 URL 里自带。

### 例 3：图片接口返回 `result.images[0].b64`

```json
{
  "path": "/api/generate",
  "body": { "prompt": "{{prompt}}", "model": "{{model}}" },
  "response": { "items": "result.images", "b64": "b64" }
}
```

## 五、能力与价格怎么填

| 项 | 说明 |
| --- | --- |
| 参考图上限 | 超过会在提交前被拒绝，不会消耗额度 |
| 单次最多张数 | 视频固定 1；图像按模型实际 `n` 上限 |
| 支持能力 | 只影响界面提示与校验；「参考图」勾选后才会出现参考槽 |
| 时长 / 分辨率（仅视频） | 决定创作台展示的选项；图像画幅与 1K/2K/4K 是全局能力，不需要配置 |
| 计费方式 | `每张` / `每次` / `每秒` / `不计价`，只用于本地估算和统计 |

价格不会发给上游，也不代表真实账单。想看真实花费，可以按你的套餐单价填一个近似值。

## 六、排错

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 401 / 403 | key 错、未开通模型、额度用尽 | 在「密钥」里测试，确认站点余额 |
| 404 | 服务地址少了 `/v1`，或路径不匹配 | 测试连接会返回 `/models` 结果；自定义接口核对 `path` |
| 429 | 限流 | 多加几个 key，或把并发调小 |
| `不可用` / `没有可用密钥` | 参考图超限 / 画幅或清晰度不支持 / 渠道没有可用 Key | 模型列表会直接显示原因；任务详情里的 attempts 也有记录 |
| `不确定，待核对` | 网络超时，请求可能已提交 | 先看上游后台记录，确认没扣费再点重试 |
| 视频无封面 | 本机缺少 ffmpeg/ffprobe | 安装 ffmpeg 并加入 PATH；不影响视频文件 |
| 参考库导入报"不在允许目录" | 目录不在 data 或设置页白名单 | 在「设置 → 参考库目录」添加该盘符目录 |

## 七、用 API 自动化

```bash
# 提交
curl -X POST http://127.0.0.1:8787/api/generate \
  -H 'content-type: application/json' \
  -d '{"model_id":"<model-id>","prompt":"雨夜天台","count":2,"params":{"aspect_ratio":"4:3","resolution":"2K"},"refs":[]}'

# 查询
curl http://127.0.0.1:8787/api/jobs/<job-id>

# 下载第一张
curl -OJ http://127.0.0.1:8787/api/assets/<asset-id>/file?dl=1
```

`/docs` 有完整的 OpenAPI 文档，可以直接在线调试。
